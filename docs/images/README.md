- 背景：由维护者提供，仅用于展示，不随 Gantt 插件安装，也不修改插件默认设置。
- 图片只包含插件内容区域，PNG 不包含文本或 EXIF 元数据。
- 截图显示嵌入模式；Gantt 也支持独立视图，Carrot Home 不是必需依赖。
